Source files for [Little Menace](https://sosonn.itch.io/little-menace), a game on itch.io.
The game was made with Unity in 3 days for the Jame Gam Game Jam (for teenagers!).
You can rate the game [here](https://itch.io/jam/jame-gam-game-jam/rate/5232240) before October 29 at 5 PM EDT.

**Game Description:**
You've got 3 lives and a whole army of foes to take down. As you kill more enemies, you will unlock new weapons with greater destructive power. Be careful, those guns are BIG.

The last commit that was uploaded on itch and submitted to the Jame Gam Game Jam is [world (terrain) generation; audio effects; hearts ui; game cycle and more](https://github.com/sosonngh/Little-Menace/commit/8cf48a2ad299823e4cc65994b12d92679eb94ba2) from October 25 6:06 PM EDT.
